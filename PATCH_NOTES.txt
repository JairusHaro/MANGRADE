MangGrade update patch
======================

Files included:
- lib/: updated scan flow, image preview, and explicit simulated-result labeling
- pubspec.yaml: adds image_picker
- test/: starter unit tests
- README.md: updated setup and project status
- backend/main.py: safer upload validation and model-status endpoint
- backend/requirements.txt: same pinned packages rewritten as UTF-8

Apply by extracting this archive into the existing Flutter project root and allowing file replacement.

Then run in PowerShell:
  flutter pub get
  flutter test
  flutter analyze
  flutter run

Important:
- The trained TFLite model is still not connected.
- The grade and confidence remain simulated demo values.
- pubspec.lock must be regenerated by `flutter pub get` because image_picker is a new dependency.
- The backend is an optional image-validation prototype and is not connected to Flutter in this on-device architecture.
- I could not run Flutter tests or Android builds in this environment because the Flutter/Dart SDK is not installed here.
